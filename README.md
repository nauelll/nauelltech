# Nauell Tech — Website Company Profile

Website company profile statis untuk Nauell Tech. Dibuat dengan HTML, CSS, dan JavaScript tanpa framework atau backend, sehingga mudah diunggah ke GitHub dan dapat dipublikasikan melalui GitHub Pages.

## Isi
- `index.html` — struktur halaman, konten, SEO dasar, dan tautan WhatsApp
- `styles.css` — desain responsif
- `script.js` — navigasi mobile dan tahun otomatis
- `assets/logo-nauell-tech.png` — logo yang diberikan

## Menjalankan secara lokal
Cukup buka `index.html` di browser. Untuk pengalaman lebih baik, jalankan server lokal, misalnya dengan ekstensi Live Server di VS Code.

## Publikasi melalui GitHub Pages
1. Buat repository baru di GitHub.
2. Upload seluruh isi folder ini (pastikan `index.html` berada di root repository).
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`, lalu klik **Save**.
6. Tunggu proses publikasi selesai. GitHub akan menampilkan URL website.
